# RiskAI Portable Distribution

## Quick Start

### Prerequisites
- Python 3.9+ (https://python.org)
- Node.js 16+ (https://nodejs.org)

### Running RiskAI

**On macOS/Linux:**
```bash
./start_riskai.sh
```

**On Windows:**
```cmd
start_riskai.bat
```

### Manual Setup

1. **Backend Setup:**
   ```bash
   cd backend
   pip install -r requirements.txt
   python api.py
   ```

2. **Frontend Setup (in new terminal):**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Access the Application:**
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8000
